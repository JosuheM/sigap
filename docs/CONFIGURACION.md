\# Configuración de SIGAP



\- SIGAP\_DB: ruta del archivo de la base de datos SQLite.

\- SIGAP\_SECRET: clave de sesión; es obligatoria en producción.

\- SIGAP\_HTTPS=1: activa la cookie Secure cuando se usa HTTPS.



Cambiar las contraseñas de demostración (admin, acopio1, ventas1)

antes de usar datos reales.
